# W3A CSS Framework

Легковесный, семантический и модульный CSS-фреймворк с поддержкой темной темы из коробки. Разработан для создания чистых, доступных и быстрых интерфейсов без необходимости писать сотни вспомогательных классов.

## ✨ Особенности

- **Semantic-First (Classless):** Базовые элементы (`<nav>`, `<table>`, `<button>`, `<input>`) выглядят отлично без добавления каких-либо классов.
- **Автоматическая темная тема:** Использует `prefers-color-scheme` и CSS-переменные. Поддерживает ручное переключение через атрибут `data-theme`.
- **Модульная архитектура:** Код разбит на логические файлы с префиксами, что гарантирует правильный порядок каскада (CSS Cascade) при сборке.
- **Нулевые зависимости:** Чистый Vanilla CSS. Никаких npm, webpack или тяжелых препроцессоров.
- **Готов к PHP-сборке:** Полностью совместим с встроенным компилятором ассетов (`App\Core\Asset`), который автоматически объединяет, минифицирует и добавляет cache-busting.

## 📂 Структура файлов

Файлы пронумерованы для строгого контроля порядка компиляции. Чем меньше число, тем ниже уровень абстракции и тем раньше файл подключается в итоговый бандл.

```text
css/
├── 00_variables.css    # CSS-переменные (:root), цветовая палитра, светлая/темная темы.
├── 01_reset_typo.css   # Базовый сброс и стили для семантических HTML-элементов (body, h1-h6, a, nav, table, form).
├── 02_components.css   # Компоненты, не имеющие семантических тегов (alert, modal, tag, pagination) + модификаторы (.is-*).
├── 03_utilities.css    # Утилитарные классы (.hidden, .bold, .text-center, .mb1).
└── 99_w3a_specific.css # Специфичные стили проекта (агрегатор новостей), переопределяющие базовые при необходимости.

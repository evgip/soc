## 📖 О проекте

**W3A** — независимая платформа где публикуют глубокие статьи, делятся опытом и ведут осмысленные обсуждения.

Проект с фокусом на:

- 🎯 **Качество контента** вместо виральности
- 👤 **Контроль читателя** над своей лентой
- 🔒 **Приватность** без трекеров и продажи данных
- 🏗️ **Открытый код** и расширяемая архитектура

---

## ✨ Основные возможности

### 📰 Для читателей
- **Умная лента** с четырьмя секциями: рекомендации, тренды, выбор редакции, новые публикации
- **Персонализация** через подписки на авторов и теги
- **Закладки** и история прочитанного
- **Тёмная тема** с автоопределением системной настройки
- **RSS-ленты** для любой секции

### ✍️ Для авторов
- **Блочный редактор** на базе Editor.js (заголовки, списки, цитаты, код, изображения)
- **Paywall** — закройте часть статьи для подписчиков
- **Статистика** просмотров и времени чтения
- **Подписчики** и уведомления о новых комментариях

### 💬 Обсуждения
- **Вложенные комментарии** с сортировкой по Wilson Score
- **Голосование** за статьи и комментарии
- **Карма** пользователей и система модерации
- **Жалобы** и предложения правок

### 🛡️ Модерация
- **Выбор редакции** (Staff Picks) — кураторские подборки
- **Система флагов** для жалоб
- **Журнал модерации** с полной историей
- **Предложения правок** от сообщества

## 🏗 Архитектура

Проект построен на **собственном MVC-фреймворке [w3a-core](https://github.com/evgip/w3a-core)** с модульной архитектурой.

### Технический стек

| Компонент | Технология |
|---|---|
| **Backend** | PHP 8.1+ |
| **Фреймворк** | w3a-core (собственный, PSR-совместимый) |
| **База данных** | MySQL 5.7+ / MariaDB 10.3+ |
| **Frontend** | Vanilla JS (без тяжёлых библиотек) |
| **Редактор** | Editor.js 2.30+ |
| **Кэширование** | FileCache (собственный, без Redis) |
| **Стили** | Собственный CSS-фреймворк |

### Модули проекта

```
app/Modules/
├── Stories/          # Статьи: CRUD, рекомендации, тренды, Staff Picks
├── Comments/         # Комментарии: дерево, Wilson Score, редактирование
├── Votes/            # Голосование за статьи и комментарии
├── Users/            # Профили, настройки, карма
├── Auth/             # Регистрация, вход, восстановление пароля
├── Subscriptions/    # Подписки на авторов и теги
├── Notifications/    # Уведомления в реальном времени
├── Messages/         # Личные сообщения
├── Saved/            # Закладки
├── Muted/            # Игнор-листы
├── Flags/            # Жалобы на контент
├── Suggestions/      # Предложения правок
├── Tags/             # Теги и категории
├── Wiki/             # Wiki-страницы для тегов
├── Search/           # Полнотекстовый поиск
├── Stats/            # Статистика
├── Mod/              # Инструменты модерации
├── Admin/            # Админ-панель
├── Invitations/      # Система приглашений
├── Rss/              # RSS-ленты
└── Common/           # Общие компоненты (Layout, CacheHelper)
```

## 🚀 Установка

### Требования

- PHP 8.1+ с расширениями: `pdo_mysql`, `mbstring`, `json`, `fileinfo`
- MySQL 5.7+ или MariaDB 10.3+
- Composer
- Веб-сервер (Apache/Nginx)

### Шаги установки

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/ваш-аккаунт/w3a.git
cd w3a
```

**2. Установите зависимости**

```bash
composer install
```

**3. Настройте окружение**

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
APP_NAME=W3A
APP_URL=http://localhost
APP_ENV=development

DB_HOST=127.0.0.1
DB_NAME=w3a
DB_USER=root
DB_PASS=

INVITATIONS_ENABLED=false
```

**4. Создайте базу данных**

```sql
CREATE DATABASE w3a CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

**5. Импортируйте схему**

```bash
mysql -u root -p w3a < database/schema.sql
```

**6. Создайте необходимые папки**

```bash
mkdir -p storage/cache/data
mkdir -p storage/logs
mkdir -p public/uploads/avatars
chmod -R 755 storage public/uploads
```

**7. Настройте веб-сервер**

Document root должен указывать на `public/`:

**Nginx:**
```nginx
server {
    listen 80;
    server_name w3a.local;
    root /path/to/w3a/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

**8. Откройте сайт**

Перейдите на `http://localhost` и зарегистрируйте первого пользователя — он автоматически получит права администратора.

## ⚙️ Конфигурация

### Основные конфиги

| Файл | Назначение |
|---|---|
| `app/Config/app.php` | Общие настройки приложения |
| `app/Config/database.php` | Подключение к БД |
| `app/Config/cache.php` | Настройки кэширования |
| `app/Config/storage.php` | Диски для хранения файлов |
| `app/Config/security.php` | Rate limiting, CSRF |
| `app/Config/invitations.php` | Система приглашений |

### Rate Limiting

По умолчанию включена защита от спама:

- **Глобальный:** 100 запросов/мин на IP
- **Для авторизованных:** 300 запросов/мин
- **Регистрация:** 5 попыток/час
- **Комментарии:** 30/мин

Настройки в `app/Config/security.php`.

## 📚 Использование

### Написание статьи

1. Войдите в аккаунт
2. Нажмите **"➕ Создать"** в шапке
3. Начните с заголовка (H1 или H2)
4. Добавьте контент через блочный редактор:
   - `/` — меню блоков
   - `Ctrl+Shift+C` — встроенный код
   - `Ctrl+Shift+K` — блок кода
5. Выберите теги
6. Нажмите **"Опубликовать"**

### Paywall (закрытый контент)

1. В редакторе добавьте блок **"🔒 Замок"**
2. Всё, что ниже замка, будет доступно только:
   - Авторизованным пользователям (`members`)
   - Или только подписчикам автора (`subscribers`)

### Выбор редакции (Staff Picks)

Администраторы могут отметить лучшие статьи:

1. Откройте статью
2. Меню **⋯** → **"⭐ В выбор редакции"**
3. Статья появится в сайдбаре на главной
